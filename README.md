🎓 Guia Universidades Curitiba
Um guia prático e centralizado com informações sobre as principais faculdades e universidades de Curitiba. O objetivo é ajudar estudantes a comparar instituições, cursos, localizações e avaliações.
✨ Funcionalidades
- [ ] Listagem de universidades de Curitiba
- [ ] Busca por curso e bairro
- [ ] Informações sobre vestibular, nota MEC e mensalidade
- [ ] Mapa com localização das instituições
- [ ] Avaliação de alunos
🚀 Tecnologias
- HTML5 / CSS3
- JavaScript
📂 Como rodar o projeto
1. Clone o repositório:
git clone https://github.com/Thais-Mainardes/Guia-Universidades-Curitiba-.git
2. Entre na pasta:
cd Guia-Universidades-Curitiba-
3. Abra o arquivo `index.html` no navegador.
